نموذج الأسئلة يحفظ محليًا على جهاز الزائر فقط، ويحتاج ربطًا لاستقبال الأسئلة فعليًا.

للرفع إلى GitHub: فك الضغط ثم ارفع محتويات المجلد مع الحفاظ على ترتيب الملفات.
